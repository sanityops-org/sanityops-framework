# Preview — Upcoming Research & Releases

**Sharing SanityOps' next research directions and version plans with the community. Some entries are exploratory directions, others are already-formed framework methodologies — the first release opened here is DMC v1.4.**

---

## Why Preview?

Preview is how SanityOps shares its upcoming research directions and version plans with the community. Some entries are only research directions, while others are already-formed framework methodologies. The first release opened here is **DMC v1.4**, a significant update to **SanityOps Framework v2.0** (planned for December 2026).

DMC's quantitative assessment of derivative-model capability degradation — and its support for different enterprise Agent types — are early contributions in the industry. DMC also moves SanityOps Framework from Agent-only governance toward a more comprehensive, multi-dimensional governance of the enterprise AI ecosystem.

---

## What's in Preview

<div class="grid cards" markdown>

- ### [DMC v1.4](/DMC/DMC.html)

    Derivative Model Capability Assessment.

    Measures whether a weight-modified (quantized / pruned / distilled / fine-tuned) model can take on a given class of enterprise tasks. Reverse-generates test cases from the enterprise's own Logic Artifacts, scores only with a program, and outputs a Decision Matrix across five capability dimensions and three functional roles (Generative / Evidential / Executing).

    **Status**: preview for SanityOps Framework v2.0 (December 2026)

</div>
